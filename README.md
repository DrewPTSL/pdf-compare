# Redline

**Site plan comparator for PDF revisions.**

Compare two versions of a site plan directly in your browser.

### Features

* PDF comparison
* Overlay, swipe, blink, and side-by-side views
* Adjustable diff sensitivity
* Zoom, pan, and magnifier
* Multi-page PDF support
* PDF diff export
* Keyboard shortcuts
* Client-side processing

### Usage

1. Load the **previous** and **current** PDF.
2. Select pages if needed.
3. Choose a comparison view.
4. Adjust sensitivity.
5. Export the diff if needed.

### Built with

HTML, CSS, JavaScript, [PDF.js](https://mozilla.github.io/pdf.js/), and [jsPDF](https://github.com/parallax/jsPDF).
